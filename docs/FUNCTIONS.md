# Описание функций
---

## circle.py

### `area(r)`
Вычисляет площадь круга радиуса `r`.

**Параметры:**
- `r` (`float`): радиус круга.

**Возвращает:**
- `float`: площадь круга.

**Пример:**
```python
>>> area(3)
28.274333882308138
```

### `perimeter(r)`
Вычисляет длину окружности круга радиуса `r`.

**Параметры:**
- `r` (`float`): радиус круга.

**Возвращает:**
- `float`: длина окружности круга.

**Пример:**
```python
>>> area(3)
18.84955592153876
```

## square.py

Вычисляет площадь квадрата со стороной `a`.

**Параметры:**
- `a` (`float`): сторона квадрата.

**Возвращает:**
- `float`: площадь квадрата.

**Пример:**
```python
>>> area(3)
9
```

### `perimeter(a)`
Вычисляет периметр квадрата со стороной `a`.

**Параметры:**
- `a` (`float`): сторона квадрата.

**Возвращает:**
- `float`: периметр квадрата.

**Пример:**
```python
>>> area(3)
12
```

## rectangle.py

### `area(a, b)`
Вычисляет площадь прямоугольника со сторонами `a` и `b`.

**Параметры:**
- `a` (`float`): длина основания прямоугольника
- `b` (`float`): высота прямоугольника

**Возвращает:**
- `float`: площадь прямоугольника.

**Пример:**
```python
>>> area(3, 4)
12
```

### `perimeter(a, b)`
Вычисляет периметр прямоугольника со сторонами `a` и `b`.

**Параметры:**
- `a` (`float`): длина основания прямоугольника
- `b` (`float`): высота прямоугольника

**Возвращает:**
- `float`: периметр прямоугольника.

**Пример:**
```python
>>> area(3, 4)
14
```
