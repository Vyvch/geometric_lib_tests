# Вычислятор

Проект реализует набор функций для вычисления площади и периметра геометрических фигур:
- круга;
- квадрата;
- прямоугольника.

## Основная идея
Каждая фигура (круг, квадрат, прямоугольник) имеет отдельную функцию для вычисления площади и периметра.
Код написан на Python, структура проекта разделена на модули.

## Используемые технологии
- Язык программирования: **Python 3**
- Библиотека: **math** (для получения значения числа π)
- Формат документации: **Markdown**
- Система контроля версий: **Git**



# Описание функций

## circle.py

### `area(r)`
Вычисляет площадь круга радиуса `r`.

**Параметры:**
- `r` (`float`): длина радиуса круга.

**Возвращает:**
- `float`: площадь круга.

**Пример:**
```
>>> area(3)
28.274333882308138
```

### `perimeter(r)`
Вычисляет длину окружности круга радиуса `r`.

**Параметры:**
- `r` (`float`): длина радиуса круга.

**Возвращает:**
- `float`: длина окружности круга.

**Пример:**
```
>>> area(3)
18.84955592153876
```

## square.py

### `area(a)`
Вычисляет площадь квадрата с основанием `a`.

**Параметры:**
- `a` (`float`): длина основания квадрата.

**Возвращает:**
- `float`: площадь квадрата.

**Пример:**
```
>>> area(3)
9
```

### `perimeter(a)`
Вычисляет периметр квадрата с основанием `a`.

**Параметры:**
- `a` (`float`): длина основания квадрата.

**Возвращает:**
- `float`: периметр квадрата.

**Пример:**
```
>>> area(3)
12
```

## rectangle.py

### `area(a, b)`
Вычисляет площадь прямоугольника со сторонами `a` и `b`.

**Параметры:**
- `a` (`float`): длина основания прямоугольника
- `b` (`float`): длина высоты прямоугольника

**Возвращает:**
- `float`: площадь прямоугольника.

**Пример:**
```
>>> area(3, 4)
12
```

### `perimeter(a, b)`
Вычисляет периметр прямоугольника со сторонами `a` и `b`.

**Параметры:**
- `a` (`float`): длина основания прямоугольника
- `b` (`float`): длина высоты прямоугольника

**Возвращает:**
- `float`: периметр прямоугольника.

**Пример:**
```
>>> area(3, 4)
14
```
